# Sebastian Paszek — Portfolio

My personal portfolio with experience, projects, skills and a few mini games.

[View portfolio](https://sebecznik.github.io/portfolio/)

Built with HTML, CSS and JavaScript. Available in English and Polish, with light and dark themes.

## Development

Edit files in `src/`, then rebuild:

```sh
python3 scripts/build.py
```

Open `index.html` in a browser to preview the site.
