01 — MOBILE APPLICATION

SanitariuszApp

A shared workspace for daily patient-care operations. Patient records, procedures and shift handovers, brought together in a cross-platform mobile app.

  • Kotlin
  • Compose Multiplatform
  • Firebase
  • Android / iOS
Explore the project

THE PROBLEM

Working in healthcare showed me how important clear information and a well-organized handover are. This project brings those daily workflows into one interface.

THE APPROACH

Kotlin and Compose Multiplatform for Android and iOS, with local persistence and Firebase Firestore synchronization. The app includes role-aware patient management, procedure tracking and administrative tools.

My focus: application development, workflow design and cross-device data synchronization.

02 — AI & WEB APPLICATION

YouTube Comments Analyzer

From a busy comment section to a clearer picture. A web application for exploring discussions, spotting recurring topics and asking questions about the comments.

  • Python
  • JavaScript
  • Gemini API
Explore the project

THE PROBLEM

A long comment section contains useful feedback, but finding patterns manually is slow. I wanted a more practical way to explore what an audience is talking about.

THE APPROACH

A Python backend with a JavaScript interface. It collects and processes comments, surfaces popular entries and recurring topics, flags potential spam and uses the Google GenAI SDK for contextual Q&A.

My focus: data processing, the web interface and Gemini integration.
